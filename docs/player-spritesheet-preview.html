Spritesheet Preview

Preview animasi dari spritesheet SpineBones. Pilih semua file hasil export sekaligus agar single-sheet maupun multi-sheet langsung terbaca.

Pilih semua file hasil export sekaligus: untuk single-sheet pilih `spritesheet.json` dan `spritesheet.png`, untuk multi-sheet pilih juga `spritesheets-manifest.json` beserta semua file `spritesheet-xx.json/png`.
